# Yeti - The Himalayan Kitchen, Baner

Auto-generated website for Yeti - The Himalayan Kitchen, Baner — Restaurant, First Floor, Yeti - The Himalayan Kitchen, Baner, Atria Building, Baner Rd, Kapil Malhar, Baner Gaon, Baner, Pune, Maharashtra 411069.

## Tech Stack

- **backend**: Spring Boot 3.x + Spring Data JPA + Spring Security
- **hosting**: AWS App Runner (backend) + Vercel (frontend)
- **database**: PostgreSQL
- **frontend**: React 19 + Tailwind CSS + Shadcn/UI
- **paymentGateway**: Razorpay

## Features

- Online Table Reservation System
- Online Ordering for Delivery & Takeaway
- Interactive Digital Menu with High-Quality Images
- Mobile-First Responsive Design
- Integration with Google Business Profile for Reviews and Info
- Clear Contact Information, Address, and Embedded Map

## Running Locally

```bash
docker-compose up --build
```

The app will be available at http://localhost:8080

## Development

**Backend:**
```bash
cd backend && mvn spring-boot:run
```

**Frontend:**
```bash
cd frontend && npm install && npm run dev
```
